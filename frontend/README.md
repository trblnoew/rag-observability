# RAG Observatory UI

React + TypeScript + Vite. 무료 데모가 기본이며 실측 실험 JSON은 번들에 포함된다.

```powershell
npm ci
npm run dev
```

`http://localhost:5173` · Node 22.12+ 또는 24 LTS/npm.

`npm test`, `npm run build`, `npm run e2e`로 검증한다. 브라우저 테스트는 Windows Edge를 사용한다. 실행 방법과 실제 연결/무료 통합 테스트/export 안내는 [Frontend 실습 문서](../docs/frontend-demo.md)를 참고한다.

API Key를 프론트 코드·환경변수에 넣지 않는다. 서버는 localhost 전용이다.
